# Metro Control Room Operator Console
## Advanced UI/UX Project Report

## 1. Project Abstract

The Metro Control Room Operator Console is a web-based interface designed to support metro operations through a centralized dashboard. It provides operators with a unified view of train monitoring, fault alerts, passenger incidents and shift management.

The prototype demonstrates how an organized digital interface can improve operational visibility, simplify information access and support coordinated decision-making.

## 2. Problem Statement

Metro control room operators need to monitor multiple operational activities simultaneously. Managing train information, technical faults, passenger incidents and emergency assistance through separate workflows can make information difficult to track.

The project addresses this problem by proposing a centralized operator console that brings important operational information and actions together.

## 3. Project Objectives

- Develop a centralized metro operations dashboard.
- Provide clear train monitoring information.
- Display and manage operational fault alerts.
- Support passenger incident reporting and tracking.
- Demonstrate emergency assistance coordination.
- Provide shift information and handover support.
- Create a consistent and user-friendly interface.

## 4. Scope of the Project

The project focuses on designing and developing an interactive front-end prototype.

The scope includes:
- Overview dashboard.
- Train monitoring.
- Fault alert management.
- Passenger incident management.
- Simulated emergency assistance dispatch.
- Shift management.

## 5. User Research

The research stage identifies potential operator needs and important operational workflows.

Research activities include:
- Defining target users.
- Preparing interview questions.
- Identifying operational challenges.
- Understanding information requirements.
- Identifying possible design opportunities.

Detailed research documentation is maintained in the Research folder.

## 6. User Personas and Empathy Mapping

The primary intended user is a metro control room operator.

Important user needs include:
- Quick access to train information.
- Clear identification of critical alerts.
- Simple passenger incident reporting.
- Easy coordination of assistance.
- Organized shift handover information.

Personas and empathy maps can be developed further using actual user interviews.

## 7. User Journey

The proposed operator journey consists of:

1. Accessing the control room dashboard.
2. Reviewing the overall metro network status.
3. Monitoring train operations.
4. Identifying and acknowledging fault alerts.
5. Recording passenger incidents.
6. Selecting and simulating assistance dispatch.
7. Updating incident status.
8. Completing shift handover activities.
