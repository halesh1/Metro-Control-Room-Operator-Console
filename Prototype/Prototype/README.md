# Metro Control Room Operator Console

## Interactive Web Prototype

The Metro Control Room Operator Console is a web-based prototype designed to help metro control room operators monitor train operations, manage technical faults, coordinate passenger incidents and handle shift activities through a centralized dashboard.

## Project Overview

The system provides a centralized interface that helps operators observe metro network activities and respond to operational situations efficiently.

## Features

### 1. Overview Dashboard
- Centralized operational dashboard.
- Network overview and operational indicators.
- Summary of trains, alerts and passenger incidents.

### 2. Train Monitoring
- View train identification details.
- Monitor train locations and destinations.
- Display train speed and operational status.
- Identify normal, delayed and faulty trains.

### 3. Fault Alerts
- Display active operational alerts.
- Identify fault severity.
- Acknowledge alerts.
- Resolve alerts after action.

### 4. Passenger Incident Management
- View passenger incident details.
- Report new incidents.
- Select assistance options:
  - First Aid Team
  - Ambulance
  - Medical Doctor
  - Emergency Response Team
- Simulate assistance dispatch.
- Track incident progress and resolution.

### 5. Shift Management
- Display current operator shift information.
- Show operator details.
- Maintain shift handover information.
- Provide a handover checklist.

## How to Run the Project

1. Clone or download this repository.
2. Open the Prototype/Prototype folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Explore the dashboard and its different sections.

## Important Note

This is an academic demonstration prototype. Train information, operational alerts and emergency assistance dispatch actions use simulated data. The application does not connect to real metro infrastructure or contact actual emergency services.

## Project Objective

The objective is to demonstrate how a centralized digital control room interface can support metro operations, improve information visibility and help operators coordinate responses to operational and passenger-related incidents.
